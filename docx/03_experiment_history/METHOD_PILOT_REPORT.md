# 阶段二/三先导：关系贡献预测与低后悔选择

## 实现

当前先导已实现：

- 按原视频五折 GroupKFold；每折重新训练联盟模型和三个单模态探针；
- 每个训练样本的联盟概率与联盟交叉熵都来自未见过该样本的模型；
- 关系预测器输入冻结表示、校准单模态概率、候选联盟概率、JS divergence、预测一致性和投影余弦相似度；
- 输出七个联盟的均值损失和异方差；
- 联合优化 Gaussian NLL、联盟排序、完整上下文贡献符号和 oracle 分布蒸馏；
- 在独立 calibration split 上选择风险系数与切换边际；
- 测试推理不访问标签或真实联盟损失。

## 判断

创新二目前只有弱到中等的排序信号，创新三没有通过“降低测试后悔值”的最低要求。MOSI/MOSEI 的 calibration 与 test 对切换策略存在明显分布差异，导致校准集上更优的 selector 在测试集退化。

因此：

1. 不运行五训练种子的正式方法实验；
2. 不声称当前关系预测器或 sparse selector 有效；
3. 保留所有负结果，防止以后重复无效路线；
4. 先完成独立任务观测，判断 RCG 是否超出文本主导情感数据；
5. 若跨任务现象成立，下一方法版本应把目标改为带覆盖率约束的 selective risk，或直接预测“相对完整联盟是否安全改善”，不再回归全部逐样本 realized CE。
