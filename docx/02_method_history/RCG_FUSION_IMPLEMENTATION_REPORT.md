# RCG-Fusion 实现与首轮方法验收报告

## 完成内容

计划中的三个连续模块已经实现：

1. 联盟有效 Transformer 任务骨干，支持二模态和三模态全部非空联盟；
2. 五折、多教师种子的 OOF 贡献监督、教师方差、边贡献、精确 Shapley 和融合后悔；
3. 关系感知异方差风险预测、排序/安全改善/符号联合损失；
4. 联合 conformal 校准和完整融合安全回退；
5. MOSI、MOSEI、CREMA-D、AV-MNIST 统一加载；
6. 高斯噪声、特征遮蔽和整模态缺失压力测试；
7. 无标签推理接口、逐样本 Parquet、统计 CSV、检查点和自动 go/no-go 报告。

全套 39 项测试通过。MOSI 压力测试烟雾运行生成 67 个条件和 43,952 条逐样本记录；所有整模态缺失条件均未选择包含缺失模态的非法联盟。

## 迭代中得到的诊断

- 自由风险回归头把无需学习的置信风险排序从约 0.61–0.67 降至约 0.49；加入置信风险锚点后恢复到约 0.63，并明显改善伤害 AUROC。
- 对各联盟绝对损失分别构造联合区间时，区间过宽并导致完全回退。直接校准相对完整融合的改进量后仍几乎不切换，说明主要瓶颈不只是相关误差重复计算。
- 直接按预测风险 `argmin` 选择时，五个种子只有一个降低后悔，其余四个增加后悔；错误选择虽数量有限，但损失幅度较大。
- 使用与正式骨干同种子的 OOF 教师目标没有解决问题。当前瓶颈是样本级 realized cross-entropy 改进的可预测性，而不是简单的教师平均错配。

## 研究判断

观测实验揭示的 Reliability–Contribution Gap 仍然成立；失败的是当前“先精确预测每个样本的 realized CE，再进行带保证联盟切换”的解决方案。这个负结果说明，论文方法不应继续把精确 oracle 联盟恢复作为主要可部署目标。

下一轮应先重新定义创新二和创新三的可学习目标，例如预测条件期望后悔或直接控制有害切换风险，并通过留出数据验证风险—覆盖曲线。只有 MOSI 上达到后悔下降和覆盖门槛后，才值得启动完整 MOSEI/CREMA-D 方法训练。现有代码和产物保留为严格基线与失败消融。
