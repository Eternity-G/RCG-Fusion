# 多联盟后验投影与风险受控收缩：实现和阶段A结果

## 实现

创新三已作为独立路径实现，没有覆盖硬切换或解析后验历史结果：

- `rcg/projected_fusion.py`：top-3联盟池、概率单纯形投影、50步投影梯度下降、完整融合收缩和解析动作风险；
- `rcg/projected_fusion_pipeline.py`：selection选择全局alpha、calibration拟合CRC、test评价及与硬切换的配对比较；
- `tests/test_projected_fusion.py`：权重单纯形、目标单调性、联盟有效性、二/三模态、零收缩和无标签推理测试。

主协议固定为 `top_k=3`、`beta=2`、50次迭代、初始学习率0.1、
`alpha ∈ {0.25,0.5,0.75,1}`、总体事件风险预算0.05和截断损害预算0.02。

## MOSI五种子阶段A结果

结果目录：`runs/rcg-projected-fusion-mosi-v1`。

| 指标 | 结果 | 门槛 | 判断 |
|---|---:|---:|---|
| 激活覆盖率 | 5.18% | ≥10% | 未通过 |
| 总体有害动作风险 | 2.01% | ≤5% | 通过 |
| 总体截断损害 | 0.041% | ≤2% | 通过 |
| NLL不劣于完整融合 | 5/5种子 | ≥4/5 | 通过 |

风险受控投影相对硬切换的NLL差为 `+0.001341`，视频簇bootstrap 95% CI为
`[-0.000687, 0.003222]`，没有显著改善。旧硬切换的平均后悔下降为0.99%，仍高于投影收缩的0.14%。

selection在五个任务种子上均选择 `alpha=0.25`。这使调整损害很小，但动作收益和超过0.01 nats的解析安全概率也同步缩小，最终CRC覆盖率不足。

## 优化器核查

50步、学习率0.1的投影梯度下降严格保持目标不增加，但在二分类MOSI上没有完全达到可解析的区间投影解。以seed 11为例，投影概率与精确凸包投影的平均绝对差为0.0235。

为排除数值收敛导致错误结论，另进行了只读的二分类精确凸包敏感性分析。精确投影的平均覆盖率为7.65%，风险为3.72%，后悔下降为0.67%，仍未达到10%覆盖率和10%后悔下降门槛。因此阶段A失败并非仅由50步优化不足造成。

## Go/No-Go判断

阶段A未通过，按预注册顺序停止：

- 不运行MOSEI、CREMA-D和AV-MNIST；
- 不启动完整主实验；
- 不根据已经查看的MOSI测试集继续调整alpha、tau、top-k或CRC预算。

当前失败说明：即使解析后验可以较好排序单联盟是否安全，将该信号用于逼近标签后验的联盟概率凸包，也只能产生很小的任务损失改进。风险控制可以限制损害，但无法创造足够大的可利用收益。
